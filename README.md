# 킹율의 퀘스트 — 메가주 일산 증정품 신청 폼

QR 찍고 레트로 게임처럼 5스테이지(약 30초)를 깨면 교환권이 나오는 이벤트 폼입니다.
모바일 폭(420px)으로 고정돼 있어서 PC에서 열어도 같은 화면이 나옵니다.

```
index.html            폼 전체 (상단 CONFIG만 수정)
assets/               도트 GIF·아이콘 (tools 스크립트로 생성)
src/                  원본 킹율 사진
tools/make_pixel_gifs.py  사진 → 도트 GIF 변환 (python3 tools/make_pixel_gifs.py)
apps-script/Code.gs   구글 시트 저장 서버
```

## 1. 구글 시트 연결 (5분)
1. 구글 시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs` 내용을 통째로 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**으로 고르고, 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 둡니다. 권한 승인을 마치면 URL이 나옵니다.
4. 그 URL을 `index.html`의 `CONFIG.SCRIPT_URL`에 넣습니다.
5. 폼을 한 번 제출해서 `신청` 탭에 행이 생기는지 봅니다. 한마디 공개에 동의한 응답은 `스토리후보` 탭에도 들어갑니다(이름·번호 없이 닉네임과 한마디만).

`SCRIPT_URL`이 비어 있으면 화면 위에 노란 DEMO 띠가 뜨고, 응답은 그 기기 브라우저에만 저장됩니다.

## 2. CONFIG에서 고칠 것
| 항목 | 설명 |
|---|---|
| `KAKAO_CHANNEL_URL` | 카카오톡 채널 주소. 비워 두면 버튼이 숨겨집니다 |
| `BOX_RULES` / `BOX_DEFAULT` | 관심 주제별 증정 박스. 위에 있는 규칙이 먼저 적용됩니다 (지금: 보험→A, 훈련→B, 나머지→C) |
| `BONUS_TEXT` | 선택 동의 유도 문구. 실제로 굿즈 추첨을 할 때만 쓰세요 |
| `CONSENT_VERSION` | 동의 문구를 바꾸면 버전도 같이 올리세요 (시트에 기록됩니다) |

## 3. 배포
정적 파일이라 아무 데나 올리면 됩니다. 가장 쉬운 방법은 https://app.netlify.com/drop 에 `kingform` 폴더를 끌어다 놓는 것입니다.
나온 주소로 QR을 만들어 대기 줄에 붙이세요. 줄 서 있는 동안 작성하게 하면 됩니다.

## 4. 현장 운영
- 스태프는 교환권의 **움직이는 킹율 GIF, 초 단위로 가는 시계, 빨간 도장**을 확인하고 박스를 줍니다. 멈춘 스크린샷은 받지 않습니다.
- 같은 번호로 다시 제출하면 "이미 받은 번호" 안내와 함께 처음 받은 교환권이 다시 나옵니다(서버 기준).
- 와이파이가 끊겨도 교환권은 발급됩니다. 응답은 기기에 보관했다가 연결되면 다시 보내고, 시트의 `오프라인임시번호` 열에 남습니다.
- 행사 뒤 Apps Script 편집기에서 `segmentReport`를 실행하면 관심사별 광고 동의자 수가 나옵니다. 영업 제안서 숫자로 쓰면 됩니다.

## 5. 광고 발송 규칙 (꼭 지키기)
- 발송 대상은 **매체별 동의 열로 거르세요.** 문자는 `광고_문자=Y`인 사람에게만, 카카오톡은 `광고_카카오=Y`인 사람에게만 보냅니다. 문자만 동의한 사람에게 카카오 광고를 보내면 안 됩니다.
- 메시지 맨 앞에 `(광고)`를 붙이고, 무료 수신거부 방법을 넣고, **밤 9시부터 아침 8시 사이에는 보내지 않습니다.**
- DB는 광고주에게 넘기지 않습니다. 광고주에게는 "발송"을 팝니다. 광고주가 직접 연락해야 하는 경우에는 메시지 안에서 신청한 사람에게만 **회사 이름을 밝힌 제3자 제공 동의**를 따로 받으세요.
- 필수 동의 보유기간(행사 종료 후 3개월)이 지나면, 광고 동의를 하지 않은 행은 지우세요.
- 동의 문구는 행사 전에 개인정보 전문가(변호사·노무/개인정보 컨설팅)에게 한 번 검토받으세요.
