# 킹율의 퀘스트 — 메가주 일산 증정품 신청 폼

QR 찍고 레트로 게임처럼 7스테이지(탭 위주, 약 1분)를 깨면 교환권이 나오는 이벤트 폼입니다.
모바일 폭(420px)으로 고정돼 있어서 PC에서 열어도 같은 화면이 나옵니다.

```
index.html            폼 전체 (상단 CONFIG만 수정)
assets/               도트 GIF·아이콘 (tools 스크립트로 생성)
src/                  원본 킹율 사진
tools/make_pixel_gifs.py  사진 → 도트 GIF 변환 (python3 tools/make_pixel_gifs.py)
apps-script/Code.gs   구글 시트 저장 서버
```

## 1. 구글 시트 (연결 완료)
- 시트: https://docs.google.com/spreadsheets/d/1_cC60bjZ6NTsLq2-u3CpvN9axw8aPTdZnp0z_RAIih8/edit
- Apps Script 프로젝트 `킹율 폼 서버`(시트의 확장 프로그램 → Apps Script)에 웹 앱으로 배포돼 있고, 그 URL이 `CONFIG.SCRIPT_URL`에 들어가 있습니다.
- 탭 구성
  - `신청`: 응답 원본. 한 줄에 한 명
  - `B2B요약`: 항목별 응답 수·비율·**광고동의자 수**, 견종 TOP 15, 동네 TOP 15. 수식이라 응답이 들어오면 바로 갱신됩니다. 제휴 제안서에는 이 탭 숫자만 쓰세요
  - `스토리후보`: SNS 공개에 동의한 한마디(이름·번호 없음)

**코드를 고쳤을 때:** `apps-script/Code.gs`를 편집기에 붙여넣고 저장 → **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 이렇게 하면 URL은 그대로입니다(새 배포를 만들면 URL이 바뀝니다).
**선택지를 바꿨을 때:** `index.html`의 `data-opts`와 `Code.gs`의 `DIMS`를 같이 고치고, 편집기에서 `rebuildSummary`를 실행하세요.

## 수집 항목 (B2B 관점)
| 스테이지 | 질문 | 관심 가질 업종 |
|---|---|---|
| 1 | 보호자 나이대 | 전 업종 타깃팅 |
| 2 | 견종·나이·**몸무게**·성별/중성화 | 사료(체급별 급여량), 보험(나이·견종 요율), 동물병원(중성화) |
| 3 | 시·군·구, **주거 형태**, 반려견 수 | 오프라인 매장·병원 상권, 소음/짖음 용품, 다견 가정 대용량 |
| 4 | 산책 횟수, **평일 혼자 있는 시간**, 주식 종류 | 유치원·펫시터·홈캠, 화식/생식 브랜드 |
| 5 | 건강 고민(복수), **펫보험 가입 상태** | 영양제·처방식, 보험사(“알아보는 중” = 바로 전환 대상) |
| 6 | 관심 주제, **월 지출**, 주 구매처 | 커머스·브랜드몰 입점·광고 단가 |

## 2. CONFIG에서 고칠 것
| 항목 | 설명 |
|---|---|
| `KAKAO_CHANNEL_URL` | 카카오톡 채널 주소. 비워 두면 버튼이 숨겨집니다 |
| `BOX_RULES` / `BOX_DEFAULT` | 관심 주제별 증정 박스. 위에 있는 규칙이 먼저 적용됩니다 (지금: 보험→A, 훈련→B, 나머지→C) |
| `BONUS_TEXT` | 선택 동의 유도 문구. 실제로 굿즈 추첨을 할 때만 쓰세요 |
| `MINI_GIFT` | 마케팅 수신 동의 없이 참여한 사람에게 주는 참가 기념품 이름·설명 |
| `CONSENT_VERSION` | 동의 문구를 바꾸면 버전도 같이 올리세요 (시트에 기록됩니다) |

## 4. 현장 운영
- 스태프는 교환권의 **움직이는 킹율 GIF, 초 단위로 가는 시계, 빨간 도장**을 확인하고 박스를 줍니다. 멈춘 스크린샷은 받지 않습니다.
- 교환권은 두 종류입니다. **문자·카톡 수신에 모두 동의**한 사람은 노란 `○ 박스` 교환권(빨간 도장 있음) → 메인 박스. 동의하지 않은 사람은 파란 `참가 기념품` 교환권(도장 없음) → 작은 기념품. 결과 화면에서 나중에 동의하면 같은 수령번호로 메인 박스 교환권으로 바뀌고 시트의 광고 동의 열도 Y가 됩니다.
- 같은 번호로 다시 제출하면 "이미 받은 번호" 안내와 함께 처음 받은 교환권이 다시 나옵니다(서버 기준).
- 와이파이가 끊겨도 교환권은 발급됩니다. 응답은 기기에 보관했다가 연결되면 다시 보내고, 시트의 `오프라인임시번호` 열에 남습니다.
- 행사 뒤 `B2B요약` 탭을 보면 됩니다. 업체에 줄 때는 **숫자만** 주고, 원본(`신청` 탭)은 공유하지 마세요.

## 5. 광고 발송 규칙 (꼭 지키기)
- 발송 대상은 **매체별 동의 열로 거르세요.** 문자는 `광고_문자=Y`인 사람에게만, 카카오톡은 `광고_카카오=Y`인 사람에게만 보냅니다. 문자만 동의한 사람에게 카카오 광고를 보내면 안 됩니다.
- 메시지 맨 앞에 `(광고)`를 붙이고, 무료 수신거부 방법을 넣고, **밤 9시부터 아침 8시 사이에는 보내지 않습니다.**
- DB는 광고주에게 넘기지 않습니다. 광고주에게는 "발송"을 팝니다. 광고주가 직접 연락해야 하는 경우에는 메시지 안에서 신청한 사람에게만 **회사 이름을 밝힌 제3자 제공 동의**를 따로 받으세요.
- 필수 동의 보유기간(행사 종료 후 3개월)이 지나면, 광고 동의를 하지 않은 행은 지우세요.
- 동의 문구는 행사 전에 개인정보 전문가(변호사·노무/개인정보 컨설팅)에게 한 번 검토받으세요.
